  `BOSS_DIFF` 难度表（标定结果烘入 bosses.js）。**顺带修复一个真 bug：敌方子弹对玩家的伤害
  此前硬编码 1，弹体 dmg 字段从不生效**（消融实验「该行可删而全绿」的呼应）。
- **标定结果**（M3 标尺 · 全流程语境=预扣前区消耗生命）：

- **测试语义升级**：Boss 重标定后「单种子必胜」不再成立，sim.test 改为**聚合通过率语义**

- **方法论沉淀**：`test/balance.js` 即强化学习雏形——批量确定性仿真为环境、通过率为 reward，

## v1.4 更新（2026-10-06 · 背景音乐）

按 HANDOFF 路线图第 3 项扩展，验收全绿后合入：

- **两首步进音序器合成 BGM**（零采样、零外部资源，与音效同源 Web Audio）：
  - **探索曲**（92 BPM · 低通 950Hz）：Am-F-C-G 慢板——三角波切分贝斯 + 方波小三和弦分解 + 长音铺底 + 反拍噪声帽，低通压暗作氛围底噪。
  - **Boss 曲**（148 BPM · 低通 2800Hz）：A 弗里几亚急板——锯齿波 8 分贝斯（b9 色彩）+ 四分底鼓 + 方波主旋律刺音 + 反拍重音帽，明亮高速。
- **战况自动切换**：进入首领房且 Boss 存活 → Boss 曲；击破/回普通房 → 探索曲；胜利/失败/回标题 → 停止。
  切曲带音量淡入与低通频率平滑扫频（`setTargetAtTime`），无爆音。
- **实现**：前瞻调度音序器（音频时钟为准，90ms 轮询排 0.45s 步进），标签页隐藏自动停调度、回前无爆音续排；
