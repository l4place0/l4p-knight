# v1.14 道中 / 关底难度曲线 · 2026-10-09

**道中与首领的阶段失败风险已接近，三档整局通关率也回到目标附近。** 最终独立留出各 200 局，
挑战 37.5%、标准 67.5%、休闲 98%。三档道中与首领的条件失败率差距均不超过 1.1 个百分点。
最终配置的 300 局标定与 600 局留出共 900 局，运行故障为零。

## 等难的定义

将流程拆成六段：第 1 区道中、第 2 区道中、第 3 区道中、区域守卫、第 4 区道中、最终首领。
一段道中包含该区的所有普通楼层，不是单个小房间。
**条件失败率 = 该段阵亡局数 / 实际进入该段的局数**；角色的装备与剩余生命自然继承，不回满血。
将四段道中的进入/阵亡数合并，与两场首领的进入/阵亡数合并比较，避免只看原始死亡总数导致分母错误。
每局可能贡献多个阶段的到达记录，不能把这些记录当作独立玩家或独立整局样本。

目标是压力沿流程分布，同时保持整局挑战 37%、标准 67%、休闲 99% 的定位。
六段完全相同时，理想每段失败率约为 `1 - 整局目标^(1/6)`：15.3%、6.5%、0.17%。
这只提供曲线参考，实际阶段并不独立，且允许首区教学压力较低。

## 实际改动

| 参数 | v1.13 | v1.14 |
| --- | --- | --- |
| 每个战斗房追加敌人 | 0 | 1（整层追加 3 名） |
| 普通敌人 HP（相对基础难度表） | ×1 | ×0.8，精英词条保留 |
| 每房清除补给生成概率 | 70% | 70% / 3，整层期望补给量回到约 0.7 件 |
| 道中分区承伤因子 | 均 ×1 | 第 1–4 区 ×1.6 / ×1.45 / ×1.85 / ×1.5 |
| 首领承伤因子 | 均 ×1 | 区域守卫 ×2.05 / 最终首领 ×1.5 |
| 首领 HP | 基础值 | 区域守卫 ×0.85 / 最终首领 ×0.6 |
| 三档基础承伤系数 | 0.265 / 0.2035 / 0.12 | 0.252 / 0.207 / 0.12 |

最终伤害 = 危险源伤害 × 档位基础系数 × 当前阶段因子，先缩放，再扣护盾和生命、判断不死晶片。
当前阶段由房间类型与首领类型确定，首领召唤物的危险源也走首领阶段；召唤物 HP 不套普通敌人 HP 曲线。
普通敌人速度、攻击节奏和弹幕参数保持原表；保留多房间、两波战斗、房门封锁与每层一次晶片的流程。
少量增加同屏威胁、降低单体血量，缩短首领战，避免以延长战斗时间制造难度。

这些参数集中在 `core.DIFFICULTY_CURVE`；探针 `G.curveTuning` 可供对照实验，最终标定/留出均运行实际默认配置。
历史测试的 `G.damageTuning` 仍可覆盖伤害；显式敌人 HP 探针保留优先级，绝对首领 HP 探针不会再次缩放。

## 整局通过率

与 v1.12/v1.13 相同固定 M3 AI：commit=30、trackK=3、sight=100、delay=10、dashSkip=0.6，四英雄等权。
标定为 seed 1–25，共每档 100 局；最终留出为 seed 501–550，共每档 200 局。
最终留出种子未参与参数选择。无每日修改器、本地元进度晶片、伤害注入、跳关或回满血；选晶片、购物和拾取由 AI 完成。
AI 不主动完整探索可选宝箱支路，因此结果描述该固定策略；不等于人类通关率。

| 档位 | 目标 | 最终标定 | 独立留出 | 留出 95% Wilson 区间 |
| --- | ---: | ---: | ---: | --- |
| 挑战 | 37% | 36/100 | **75/200（37.5%）** | 31.09–44.39% |
| 标准 | 67% | 67/100 | **135/200（67.5%）** | 60.73–73.61% |
| 休闲 | 99% | 97/100 | **196/200（98%）** | 94.97–99.22% |

标定均满足原 ±5 个百分点容差；留出均满足目标位于 95% 区间的验收口径，且点估计距目标至多 1 个百分点。
Wilson 区间沿用旧报告的逐局计算方式；同种子的四英雄共享环境，逐局独立假设有限。
这是固定标尺下的描述与验收，不是对人类体验或统计等效性的正式证明。
