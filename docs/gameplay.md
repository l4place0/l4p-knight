# 共同玩法与验收规格

浏览器源码是可执行参考，正式数值见 config/。其他平台依据相同 ID、配置、规则与代表场景重写，单独记录平台差异。

每层六房：入口、三个战斗房、宝箱支路、出口。未清战斗房封门，两波肃清解锁；清过的房间不再刷怪，回访保留拾取物，宝箱只领一次。三个战斗房清完后，出口领取一次晶片三选一，再通过传送门推进；区域末层经过补给站及配置的 Boss，最终 Boss 击破进入 victory。

状态为 title、playing、chip、shop、victory、defeat、paused，晶片/商店/暂停冻结世界。主武器与相位刃两个槽位，近战可弹反。伤害先护盾后生命，不灭战意按抵扣后致命伤判断、每战斗一次。

重复晶片升级，羁绊按 need 同时持有生效。商店先扣款、已售不可重复买。重开清除攻击/蓄力输入和本局经济。元进度仅 UI 门控，不限制无头仿真或调试回放。

随机数为 core.RNG 的 mulberry32，参考固定步长 1/60 秒，自有地图碰撞。确定性对照须保持种子、英雄、难度、bot 基因、输入和配置。其他引擎浮点/随机不同须说明并通过共同规则验收。

验收以 test/rooms、mechanics、difficulty、navigation、render 专项场景为准：房图连通/封门/回访/奖励、武器冷却与弹种、承伤曲线、商店、重开、Boss 阶段、空间不变量以及传送门导航。不能以空场能运行替代实际战斗验收。
