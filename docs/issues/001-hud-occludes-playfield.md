# 001 · HUD、小地图遮住角色与推进目标

- 优先级：P1
- 状态：closed（2026-10-09）
- 来源：[实际浏览器通关观察](../qa/browser-playthrough-v1.14.md)
- 修复提交：`2b5105b`

## 复现

`npm start` 后访问游戏。第二区第二层战斗 1 清场后将角色移动到右上角小地图下方：整个人物与武器被覆盖，按 S 移出覆盖区域才重新出现。左上 HUD 同样覆盖玩家与可能生成的传送门。

![现场](../qa/playthrough-v1.14/hidden-player.jpg)

## 验收条件

- 常驻 HUD、小地图、晶片列表、首领血条、交互提示不与游戏画布重叠。
- 原战斗视野完整显示，缩放与鼠标瞄准保持一致；桌面和窄屏布局不裁切。
- 地图清房/当前房状态、生命护盾、首领阶段和交互提示保持可读。

## 修复与验证

上下栏容纳常驻 HUD、独立小地图、晶片、交互提示和首领血条，画布完整保留 480×272；缩放计入栏高，窄屏不再强制最小 1 倍，长晶片列表可滚动。

真实浏览器的 1642×864、1200×1000、409×612、844×390 四尺寸检查通过。原小地图区域的角色完整显示，21 个战斗房的实战推进与结算通过。
鼠标坐标继续以游戏画布的实际矩形换算。证据和可重复回归见 [验收报告](../qa/browser-fixes-v1.14.1.md)。
