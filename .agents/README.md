# Agent 资料入口

Agent 专用资料在本目录管理，共享工程与玩法文档在 [docs/](../docs/architecture.md)。

| 位置 | 内容 |
| --- | --- |
| [handoff.md](handoff.md) | 当前交接与阅读入口 |
| [tasks/](tasks/README.md) | 进行中任务，以及按任务归档的计划、过程与脚本 |
| [notes/](notes/template.md) | 按日期平铺的会话总结；作者与已存在提交提供溯源 |
| [art/](art/) | 美术生成提示词等 Agent 过程资料 |
| [legacy/](legacy/README.md) | 旧工具与交接资料，保留历史语境 |

最近完成：[v1.15.0 工程整理与发布](tasks/archive/2026-10-09-engineering-release/README.md)。

任务完成后，将过程材料收进 tasks/archive/YYYY-MM-DD-topic/，保留一份过程索引；notes/ 的总结继续沿用既有平铺命名，不重复复制同一份总结。可重复使用的正式工程工具进入 scripts/；一次性过程脚本作为历史证据归档，不作为日常入口。
