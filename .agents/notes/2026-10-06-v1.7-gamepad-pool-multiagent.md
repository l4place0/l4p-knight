# 任务归档 · v1.7：手柄/触控 + 对象池（路线图 6+7 收官）

- **起点**：HANDOFF v1.6.1（路线图剩 6/7 两项）→ **产出**：v1.7，**路线图 7/7 全部完成**
- **协作方式**：首次多 Agent 并行迭代——三个 Agent 单消息同时派发，按文件分区严格隔离：
  A(手柄/触控:main.js+index.html) · B(对象池:仅 game.js) · C(只读 QA 扫描:不改文件)；
  编排者负责 diff 审查、QA 修复落地、集成验收与文档

## 完成内容

1. **手柄（A）**：Gamepad API 标准映射——左摇杆移动(死区 0.25,与键盘叠加)、右摇杆瞄准(aimA 通道)、
   RT 射击/LT 冲刺/X 相位刃/B 互动/LB·RB 切枪/Start 暂停；按下沿检测防连发；接入 toast；bot 接管时完全让位
2. **触控（A）**：`pointer:coarse` 或首次 touchstart 启用——左下虚拟摇杆(8px 死区,独立 pointerId+capture)、
   右下射击(自动瞄准 500px 内最近敌人,与手柄右摇杆共用 aimA 通道)/冲刺/相位刃/互动、右上暂停；
   viewport 防缩放;键鼠路径逐位不变
3. **对象池（B）**：bullets/particles/floaters/rings 四池 freelist 复用,acquire 逐一重初始化全部字段、
   整表清空走 pooledClear;**数组顺序与 RNG 消费顺序零改动**;`G.__poolStats()` 可观测
4. **QA 扫描修复（C 发现,编排者落地）**：
   - P0 商店签名跨局撞车(shopVisits 被 startRun 归零 → 二周目商店显示上一局商品)——startRun 失效 shopSig
   - P1 上局横幅残留(startRun 重置清单补 G.banner=null)
   - P1 toast 全量重建致存留提示重播动画——改按对象 Map 增量增删
   - P2 #prompt/#fps 补 pointer-events:none(此前会吞掉划过时的射击点击)
   - P2 三个 localStorage get 补形状校验(标量注入不炸标题)
5. **分帧碰撞明确不做**：会改碰撞时序/物理语义;池化已消除分配大头,仅当弹幕真正上千且不够时再议

## 遗留 / 注意事项

- **无头仿真盲区**（C 组报告确认现状干净,但此类 bug 只能靠真人/只读扫描发现）：DOM 点击目标稳定性、
  overlay 生命周期、观感/听感——每次实机验收后建议跑一轮 C 类扫描
- 对象池铁律已写入 HANDOFF 机制表：**新增弹种/实体字段必须在池 init 中重置**,否则复用泄漏
- 手柄 LT/X 为按下沿单次触发(与键盘 Shift/F 同构);若要"按住自动再冲"需改 hold 型
- 触控真机手感(摇杆半径/按钮尺寸/自动瞄准距离 500px)未经真机调参,数值在 main.js 触控段
- 8942 端口曾有 TaskStop 未杀干净的孤儿 serve 进程(Windows 下 kill shell 不杀 node 子进程),
  已直接 taskkill;后续停止服务器建议按 PID 杀
